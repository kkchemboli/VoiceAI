# Workflows Overview

This section outlines the key workflows in the LiveKit AI Voice Agent system. Each workflow describes a specific business process or technical flow, from start to finish.

## Key Workflows

| Workflow | Description |
|----------|-------------|
| [Appointment Booking](/openwiki/workflows/appointment-booking.md) | Flow for checking availability and booking appointments via calendar integration. |
| [Call Handling](/openwiki/workflows/call-handling.md) | End-to-end flow of handling an inbound or outbound call, from connection to call summary. |
| [Outbound Calling](/openwiki/workflows/outbound-calling.md) | Process for initiating outbound calls via bulk dialer or manual triggers. |
| [Call Summary & Notification](/openwiki/workflows/call-summary.md) | How call summaries are generated and sent via Telegram after a call ends. |
| [Appointment Reminders & Follow-ups](/openwiki/workflows/appointment-reminders.md) | Process for sending reminders and follow-ups for scheduled appointments. |

## How to Use This Section

Each workflow page includes:
- A high-level description of the workflow
- A Mermaid diagram illustrating the steps
- Detailed explanation of each step
- References to the relevant source code components
- Key considerations and potential failure points

For a high-level architecture overview, see the [Architecture Overview](/openwiki/architecture/overview.md).
